# Pilot test result (RUC17)
This file contains fixation data labelled by both the Old classification method and the New classification method. Here is the description of the key columns:

IFI (Inter-Fixation Interval): The temporal gap between the end of the previous fixation and the start of the current fixation (in milliseconds). Negative values are clipped to 0.
chunk_id: The fixation sequence is pre-segmented into chunks at points where the IFI exceeds a specific threshold (e.g., 99th percentile), preventing sliding windows from crossing long temporal gaps (please refer to the gaze path file for more detailed description).

GPlabel_O (Old Labels): Labels generated by the original method
L (Linear), R (Re-reading), S (Scattered)

GPlabel_N (New Labels): Labels generated by the new sliding-window classification method. The first fixation of a continuous episode is UPPERCASE (e.g., L) and subsequent fixations are lowercase (e.g., l).
L (Linear reading)
R (Re-reading)
S (Skimming)
O (Others / ambiguous patterns)
X (Cross-region / highly mixed ST-TT windows)
? (Unclassified boundary fixations that could not serve as window centres)

# Script
This file contains the gaze path classification module of the TPRDB table-generation pipeline. These scripts are not standalone programs. They are designed to be integrated into a larger script (TPR-DB_Tables.ipynb) that reads .fd files and produces the full TPRDB table. The scripts here are responsible for one specific step: assigning a gaze path label to each fixation.
