# Gaze-Path Classification in Translation Process Research

This repository contains the scripts, pilot data, and methodological documents for classifying gaze paths (eye movement patterns) during translation and post-editing tasks

## 🎯 Our Current Discussion Focus

We are currently seeking feedback on two main aspects:
1. **Conceptual Rationality:** Are the categories (`L` - Linear, `S` - Skimming, `R` - Re-reading, `O` - Others, `X` - Cross-region) conceptually sound and well-defined?
2. **Rule Rationality:** Are the logical rules and thresholds used in the decision tree valid?
   

## 🔄 Context: Pilot Data & Proposed Revisions

The current **Pilot Data** was generated using the baseline rules described in the document. However, after a recent workshop discussion, we identified several edge cases (e.g., rapid visual glides being misclassified as linear due to mathematical cancellation, limitations of the CV metric). 

Therefore, **proposed revisions** (such as introducing temporal constraints like `WIN_DUR > 0.7 * BASE_DUR`) are actively being considered. **These proposed revisions are explicitly marked in the comments of the Word document.**

## Pilot test result (RUC17)
This dataset contains fixation data labelled by both the Old classification method and the New classification method. The New classification method includes results from two different sliding window sizes (5-fixation and 7-fixation). 
Here is the description of the key columns (the last four columns in the table):

IFI (Inter-Fixation Interval): The temporal gap between the end of the previous fixation and the start of the current fixation (in milliseconds). Negative values are clipped to 0.

chunk_id: The fixation sequence is pre-segmented into chunks at points where the IFI exceeds a specific threshold (e.g., 99th percentile), preventing sliding windows from crossing long temporal gaps. (Please refer to the gaze path document for more detailed description).

GPlabel_O (Old Labels): Labels generated by the original method.

>L: Linear

R: Re-reading

S: Scattered
>

GPlabel_N (New Labels): Labels generated by the new sliding-window classification method. For continuous episodes, the first fixation is labelled in UPPERCASE (e.g., L) and subsequent fixations are lowercase (e.g., l).

L: Linear reading

R: Re-reading

S: Skimming

O: Others 

X: Cross-region / mixed ST-TT windows

?: Unclassified boundary fixations that could not serve as window centres


⚠️ Important Note on the S label:
The letter S has different meanings across the two methods. In the Old method (GPlabel_O), it stands for Scattered. In the New method (GPlabel_N), it specifically stands for Skimming. They should not be treated as equivalent.

## Script
This file contains the gaze path classification module of the TPRDB table-generation pipeline. These scripts are not standalone programs. They are designed to be integrated into a larger script (TPR-DB_Tables.ipynb) that reads .fd files and produces the full TPRDB table. The scripts here are responsible for one specific step: assigning a gaze path label to each fixation.

## Related Work
This framework builds on Carl et al. (2025) for the baseline approach, Biedert et al. (2012) for the sliding-window design, and Strukelj & Niehorster (2018) to justify using temporal constraints to distinguish genuine re-reading from transient verification checks.
